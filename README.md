# 2-axis-servo-gimbal
二维舵机云台设计说明（两自由度）  本设计为一套两自由度舵机云台，可实现水平回转与俯仰两方向独立指向，用于搭载相机、传感器或小型执行机构，在 SolidWorks 中完成三维建模与装配。  结构采用"底部回转 + 上部俯仰"的串联布局：底座固定大扭矩舵机，经金属主舵盘驱动上部绕竖直轴回转；上部由双轴短 U 型支架构成俯仰关节，两舵机轴线正交，支架内预留舵机与转轴安装位，保证转动顺畅、互不干涉。  控制端输出两路 PWM 指令给定两舵机转角，即可改变云台方位角与俯仰角，使负载指向目标。  特点：结构紧凑、零件少、装配方便；两轴正交便于配平；孔位通用，可用 3D 打印或机加工制作，适用于视觉跟踪、目标指向与传感器扫描等场合。
